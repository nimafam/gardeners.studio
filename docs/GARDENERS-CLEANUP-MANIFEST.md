# Gardeners — Cleanup Manifest

Status: approved planning manifest. This document does not authorize deletion by itself.

## Confirmed decisions

- Existing project media under `apps/web/public` belongs to work completed by Gardeners and must be preserved for reuse.
- `apps/web/public/work/**` is the protected source library for Gardeners projects and must not be deleted, renamed, overwritten, or regenerated by cleanup tasks.

- Akord brand content, copy, metadata, logo usage, and Akord-only implementations can be removed.

- Akord's WebGL and Experience architecture remains quarantined until the Figma interactions have been reviewed in detail.
- The supplied Gardeners logo becomes the new brand source, subject to asset optimization.

## Motion direction

Gardeners motion should feel deliberate and editorial without depending on a continuous 3D runtime.

Preferred default stack:

- CSS transitions for hover, focus, color, opacity, and simple transforms.
- Motion for entrance/exit, layout transitions, menus, cards, and route-level choreography.
- GSAP only for complex scroll-linked sequences that cannot be expressed cleanly with CSS or Motion.
- Lenis only if smooth scrolling materially improves the approved experience.
- WebGL only for an isolated, justified visual moment after the quarantine review.

Required behavior:

- Transform and opacity animations should be the default for performance.
- Motion tokens must define duration, easing, delay, and stagger.
- Every major animation must have a reduced-motion alternative.
- Mobile animation density should be lower than desktop.
- Page content and navigation must remain usable before animation initializes.
